## TATA Internship

## Project Overview

This project was part of the Tata Data Visualisation: Empowering Business with Effective Insights virtual internship on Forage. The objective was to analyze retail business data and create visual dashboards that help senior leaders (CEO and CMO) make strategic decisions.In this simulation, I worked as a data analyst consultant responsible for converting raw business data into meaningful visual insights that could support business growth and expansion planning.The project focused on data analysis, visualization, and business storytelling.


## Tools and Technologies Used
-Excel – Data cleaning and preprocessing
-Power BI – Data visualization and dashboard creation
-SQL/DAX (optional) – Data querying
-Git & GitHub – Version control and project documentation

## Dataset
-Invoice number
-Product description
-Quantity sold
-Unit price
-Customer ID
-Country

## Project Workflow
#Data Cleaning
-Removed missing values
-Checked for duplicate records
-Standardized data format
#Data Analysis
-Analyzed the dataset to answer key business questions such as:
-Monthly revenue trend
-Country-wise sales performance
-Top customers by revenue
#Data Visualization
-Created visual dashboards to present insights clearly.
-Example visualizations:
-Revenue trend over time
-Top countries by sales
-Customer contribution to revenue
# Business Insights
-Converted analysis results into actionable insights for stakeholders.

## Key Insights
-Revenue increased significantly in the last quarter of the year.
-Certain countries contribute a large percentage of overall revenue.
-Customer purchases are distributed across multiple regions.

## Challenges Faced 
Data Quality Issues(Negative quantities,incorrect price value,missing value)
